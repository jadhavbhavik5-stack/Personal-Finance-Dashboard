# Personal Finance Dashboard

## Overview
An end-to-end data analysis project analyzing 1.2 million credit card transactions to uncover spending patterns, monthly trends, and fraud detection insights.

## Tools Used
- **Python (pandas)** — Data cleaning and preparation
- **SQL (SQLite)** — Data analysis and querying
- **Tableau Public** — Interactive dashboard visualization

## Key Insights
- Grocery (POS) is the highest spending category at $14.4 million
- December shows the highest monthly spending — nearly double any other month
- Fraud transactions are only 0.58% of total but average 8x higher in value than legitimate ones
- Texas leads all states in total spending at $6.8 million
- Female customers make 17% more transactions than male customers
